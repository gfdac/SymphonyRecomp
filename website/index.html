GUIA DE EXECUÇÃO

Como Compilar e Jogar no PC

Passo a passo simples para rodar o jogo nativamente no Windows.

1

Clonar o Repositório

Clone a branch de desenvolvimento com todo o código unificado:

git clone -b dev https://github.com/gfdac/SymphonyRecomp.git
2

Adicionar a ROM (SLUS-00067)

Coloque a imagem do seu disco original de Castlevania SOTN (PS1) na pasta disc/.

disc/Castlevania - Symphony of the Night (USA).bin
3

Compilar & Jogar

Execute o script inicial uma única vez para extrair e compilar os binários:

.\windows_initial_build.bat

Para jogar posteriormente sem recompilar do zero:

.\windows_run_no_build.bat
